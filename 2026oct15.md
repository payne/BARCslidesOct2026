# Ideas: "Never a Better Time to be a Ham"

Aaron KC0WIH's talk ([slides](kc0wih.html)) has plenty of starting points:

- Radios are better and cheaper than ever
- An **SDR receiver for under \$40** (RTL-SDR, OpenWebRX)
- **LoRa mesh**: MeshCore and Meshtastic
- **44Net**: a public IPv4 address with your license
- **Linux** for hams: Debian Hamradio blend, DragonOS
- **Open firmware**: OpenRTX, OpenGD77
- GitHub "awesome amateur radio" lists, Hackaday

---

# Turning ideas into meetings

Possible program formats for 2027:

- **Technical presentations** from members and guest speakers
- **Show and tell**: bring the radio, the build, the log
- **Hands-on nights**: program a radio, set up an SDR, try a digital mode
- **On-air outings**: POTA activations, VHF/UHF nets, contests

> What would get *you* to a meeting?

---

# More members, more active

**Goal:** increase the number of members actively participating in the hobby and the club.

- Pair up: someone who knows a mode + someone who wants to learn it
- Short member talks: "here's what I did on the air this month"
- Make it easy to ask for help — and easy to offer it
- Invite the members we haven't seen in a while
