# BARC Slides

Marp slide decks for BARC. On every push to `main`, `.github/workflows/build-docs.yml` runs `npm run build` into `docs/` and deploys that to GitHub Pages (Pages source must be "GitHub Actions"). `docs/` is a build output and is not committed.

## Session log

At the end of every session, append a new `## Session N: YYYY-MM-DD: <topic>` section to `SESSION_LOG.md`. Each section records the user's requests, what was done and why, how it was verified, and any open items. Never rewrite earlier sessions.
