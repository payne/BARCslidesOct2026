# BARC Slides

Marp slide decks for BARC, published to GitHub Pages from `docs/` (built with `npm run build`).

## Session log

At the end of every session, append a new `## Session N: YYYY-MM-DD: <topic>` section to `SESSION_LOG.md`. Each section records the user's requests, what was done and why, how it was verified, and any open items. Never rewrite earlier sessions.
